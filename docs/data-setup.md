# Data Setup

The data files are not stored in Git. Add them to your local project before running the services.

## Folder layout

```
data/
├── raw/          # fraud dataset CSVs (input)
├── policies/     # compliance policy PDFs (input for RAG)
└── processed/    # generated by notebooks (feature files)
```

## Required files

| File | Folder | Source |
|------|--------|--------|
| `fraudTrain.csv` | `data/raw/` | [Kaggle dataset](PASTE_KAGGLE_URL) |
| `fraudTest.csv` | `data/raw/` | [Kaggle dataset](PASTE_KAGGLE_URL) |
| Policy PDF (any `.pdf`) | `data/policies/` | PASTE_POLICY_SOURCE |

## Optional files

| File | Folder | Source |
|------|--------|--------|
| `Wire transfer fraud.csv` | `data/raw/` | PASTE_SOURCE (not read by current code) |
| `fraudTrain_features.csv` | `data/processed/` | Generated by `notebooks/02-feature-engineering.ipynb` |

## Setup steps

1. Create the folders if they don't exist:
```powershell
   New-Item -ItemType Directory -Force data/raw, data/processed, data/policies
```
2. Copy each required file into its folder.
3. Verify the setup:
```powershell
   python scripts/seed.py
```
   Every required file should show `[OK]`. Missing files are listed with their expected path.
4. For the processed file, open `notebooks/02-feature-engineering.ipynb`, run all cells from the top, and save the output to `data/processed/`.

## Notes

- Keep the original filenames for the CSVs. The code and `scripts/seed.py` look for these exact names.
- Policy PDFs can have any name. A readable name such as `RBI_KYC_Master_Direction.pdf` is easier to recognize in citations.
- Do not commit files from `data/` to Git. The folder is listed in `.gitignore`.
